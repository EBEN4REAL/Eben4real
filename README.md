# 👨🏽‍💻 About Me

I'm a passionate **Senior Full-Stack Engineer** with over **8 years of experience** designing, architecting, and delivering scalable, high-performance web applications across **fintech, SaaS, enterprise, AI, and Web3**.

I specialize in building modern, scalable software from end to end—creating intuitive frontend experiences with **React, Next.js, Vue.js, and TypeScript**, while developing secure, reliable backend services using **Java, Spring Boot, Node.js, and Python**.

I enjoy solving complex engineering problems through clean architecture, scalable APIs, cloud-native development, and performance optimization. I have extensive experience collaborating with cross-functional teams to deliver products that are secure, maintainable, and loved by users.

More recently, I've been building **AI-powered applications** using **Python**, **LangChain**, **OpenAI**, **Retrieval-Augmented Generation (RAG)**, and vector databases such as **Pinecone** and **ChromaDB**, enabling intelligent and context-aware user experiences.

I'm also passionate about **Web3**, building decentralized applications and integrating blockchain technologies into modern web platforms.

My goal is simple:

> **Build world-class software that scales, delights users, and solves meaningful problems.**
